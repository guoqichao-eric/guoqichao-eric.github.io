使用说明（发布到 GitHub 后）

  1. 在本页完成内容的新增 / 修改 / 删除；
  2. 点击右上角「导出 data.js」，复制生成的内容（或直接下载文件）；
  3. 打开 GitHub 仓库根目录的 data.js，点击铅笔图标进入编辑，全选替换为导出的内容，Commit 提交；
  4. 等待 GitHub Pages 自动部署（约 1 分钟），主页即更新。

提示：相册照片需先上传到仓库 images/photos/ 目录，再在「相册」分类中填写路径。
